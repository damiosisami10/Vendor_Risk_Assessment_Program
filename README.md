# Vendor Risk Assessment Program - NorthPay Financial (Simulation)

## Overview
A functional third-party risk assessment program built using ISO 27001,
NIST CSF, and MetricStream-aligned workflow concepts. Developed as a
GRC portfolio project targeting financial services environments.

## Program Components
- Vendor Inventory Register (Google Sheets)
- Risk Scoring Matrix (5x5, ISO 27001 aligned)
- Vendor Assessment Questionnaire (5 domains, 15 questions)
- Mock Assessment Results for 3 vendors across 3 tiers
- Executive Risk Report with findings and remediation tracking

## Frameworks Applied
- ISO 27001:2022 (Clauses 8.4, Annex A)
- NIST CSF 2.0 (ID.SC, PR.AC, PR.DS, RS.RP, RC.RP)
- PIPEDA breach notification requirements

## Tools Used
- Google Sheets (risk register, scoring matrix, vendor inventory)
- Google Docs (policy, questionnaire, reporting)
